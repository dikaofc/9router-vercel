# 🎮 Deploy 9Router ke Replit

> Browser-based, zero setup.

## Quick Start

1. Buka https://replit.com
2. **Create Repl** → **Import from GitHub**
3. Pilih repo
4. Set **Secrets** (🔒): `JWT_SECRET`, `INITIAL_PASSWORD`
5. Click **Run**

---

## Limitations

- ⚠️ Sleep setelah idle (free tier)
- ⚠️ 1GB RAM (free), 4GB (Hacker plan $7/bulan)
- ⚠️ Ephemeral disk
