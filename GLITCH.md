# 🎭 Deploy 9Router ke Glitch

> Gratis, no CC, langsung dari browser. Paling gampang.

## Kenapa Glitch?

| | Glitch |
|--|--------|
| Gratis | ✅ Selamanya |
| CC | ❌ Gak perlu |
| Sleep | ⚠️ 5 menit idle → sleep |
| Cold start | ⚠️ ~5-10 detik |
| Setup | ✅ Zero — import langsung |

---

## Setup (2 menit)

1. Buka https://glitch.com
2. Login GitHub
3. Click **"New Project"** → **"Import from GitHub"**
4. Pilih repo `9router-vercel`
5. Tunggu install selesai
6. Klik **"Share"** → **"Live App"**

**Selesai!** URL langsung jadi: `https://your-project.glitch.me`

---

## Environment Variables

Glitch Dashboard → **.env** file:

```
JWT_SECRET=your-random-secret
INITIAL_PASSWORD=your-password
PORT=3000
```

## Kelebihan

- ✅ Browser-based — gak perlu install apapun
- ✅ Auto-restart kalau crash
- ✅ Built-in terminal & editor

## Kekurangan

- ⚠️ Sleep 5 menit idle (klik "Keep awake" untuk keep alive)
- ⚠️ 200 MB RAM (cukup untuk 9Router)
- ⚠️ Gak ada custom domain gratis
